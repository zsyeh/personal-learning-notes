# 8.12 英语词汇总结

## 1. inherit / inherent / heritage

### inherit
**inherit** /ɪnˈherɪt/ = 继承；遗传获得

- `inherit A from B` = 从 B 继承 A
- `inherit property` = 继承财产
- `inherit a gene` = 遗传到某基因

### inherent
**inherent** /ɪnˈhɪərənt/ = 内在的，固有的

- `be inherent in ...` = 是……固有的
- `inherent risk` = 固有风险

区分：
- `inherit` = 从上一代/外部得到
- `inherent` = 本来就在内部

### heritage
**heritage** /ˈherɪtɪdʒ/ = 遗产；传统；文化遗产

与 `inherit` 同族：

`heir → inherit → inheritance / heritage`

- `cultural heritage` = 文化遗产
- `World Heritage Site` = 世界遗产地

`inheritance` 更偏具体财产；
`heritage` 更偏历史、文化、传统。

## 2. belly

**belly** /ˈbeli/ = 肚子，腹部

- `belly fat` = 腹部脂肪
- `beer belly` = 啤酒肚
- `belly button` = 肚脐

区别：
- `belly`：口语，偏外部“肚子”
- `stomach`：胃；也可泛指肚子

## 3. throne

**throne** /θrəʊn/ = 王座；王位

词源：
`Greek thronos` = 高座、座椅

常见：
- `ascend the throne` = 登基
- `heir to the throne` = 王位继承人
- `dethrone` = 废黜，赶下王位
- `enthrone` = 使登基

不要把 `throne` 硬拆成现代词根。

## 4. gown

**gown** /ɡaʊn/ = 长袍；礼服

常见：
- `evening gown` = 晚礼服
- `wedding gown` = 婚纱
- `graduation gown` = 毕业袍
- `academic gown` = 学位袍

区别：
- `dress` = 泛指裙装
- `gown` = 长、正式、仪式性较强

---

## 5. siege

**siege** /siːdʒ/ = 围攻；围城

词源与“坐”有关：

`sedere / *sed-` = sit

语义：
`坐下驻扎 → 长期包围 → 围攻`

常见：
- `lay siege to ...` = 围攻……
- `under siege` = 遭到围攻

可联：
- `sit`
- `seat`
- `sedentary`
- `reside`
- `president`

核心词根：
**sed = sit**

---

## 6. herd

**herd** /hɜːd/ = 兽群；牧群；赶牲畜

- `a herd of cattle` = 一群牛
- `a herd of elephants` = 一群大象
- `herd mentality` = 从众心理
- `herd cattle` = 赶牛

注意：
- `herd` = 兽群
- `heard` = hear 的过去式
二者通常同音。

## 7. depict

**depict** /dɪˈpɪkt/ = 描绘；刻画

词源：
`de- + pict/ping`

`pict / ping` ≈ paint，画

所以：
`depict` = 把某物画出来 → 描绘、刻画

常见：
- `depict a scene` = 描绘场景
- `depict sb as ...` = 把某人刻画成……
- `depiction` = 描绘

联想：
- `picture`
- `pictorial`
- `depict`
- `depiction`

---

## 8. voyage

**voyage** /ˈvɔɪɪdʒ/ = 航行；远行

词源核心：
`via` = road，道路

语义：
`旅途 → 长途旅行 → 尤指海上/太空航行`

常见：
- `sea voyage` = 海上航行
- `maiden voyage` = 首航

联想：
- `via` = 经由
- `viaduct` = 高架桥
- `deviate` = 偏离道路 → 偏离
- `deviation` = 偏离

---

## 9. deplete

**deplete** /dɪˈpliːt/ = 耗尽，使枯竭

词源：
`de- + plere`

`plere` = fill，填满

所以：
`deplete` ≈ un-fill  
→ 把“满”抽空  
→ 耗尽

常见：
- `deplete natural resources`
- `deplete energy reserves`
- `depletion` = 消耗、枯竭

同族：
- `complete` = 完全填满 → 完整
- `replete` = 充满的
- `deplete` = 抽空

核心：
**ple / plete = fill**

---

## 10. enclose / enclosure

### enclose
**enclose** /ɪnˈkləʊz/ = 围住；封入；随函附上

`en- + close`

核心词根：
`claud / clud / clos` = shut，关闭

常见：
- `The garden is enclosed by a wall.`
- `Please enclose a copy.` = 请随附一份副本

### enclosure
**enclosure** = 围起来的区域；围栏；附件

`enclose + -ure`

同族：
- `close` = 关闭
- `enclose` = 围住
- `include` = 包含
- `exclude` = 排除
- `seclude` = 隔离
- `conclude` = 收束 → 得出结论

核心：
**CLAUD / CLUD / CLOS = shut**

---

## 11. volatile

**volatile** = 易挥发的；易波动的；不稳定的

词源：
`volare` = fly，飞

语义：
`飞走`
→ 易挥发
→ 易变化
→ 波动剧烈

常见：
- `volatile liquid` = 易挥发液体
- `volatile market` = 波动剧烈的市场
- `market volatility` = 市场波动性

核心：
**vol / vola = fly**

---

## 12. deputy / vice

### deputy
**deputy** /ˈdepjəti/ = 副手；代理人；副职

来源于：
`depute` = 委派、指派

侧重点：
**被授权代替某人履职**

- `deputy director`
- `deputy manager`
- `He is my deputy.`

### vice-
**vice-** = 副……

侧重点：
**正式职位等级中的副职**

- `vice president`
- `vice chairman`

区分：
- `vice-` = 占据正式“副位”
- `deputy` = 受委派代行职责

注意：
`vise` = 台钳，不是 `vice`。

## 13. wax

**wax** 有两个不同来源的核心义。

### ① wax = 蜡
- `beeswax` = 蜂蜡
- `earwax` = 耳垢

### ② wax = 增长；逐渐变得
来自古英语 `weaxan` = grow

常见：
- `wax and wane` = 此消彼长；月亮盈亏
- `wax eloquent` = 越说越起劲、滔滔不绝

对照：
- `wax` = grow
- `wane` = decrease

## 14. henceforth / forth

### forth
**forth** /fɔːrθ/ = 向前；继续向前

≈ `forward / onward`

常见：
- `go forth` = 出发
- `set forth` = 陈述；出发
- `bring forth` = 产生、提出
- `back and forth` = 来来回回

### henceforth
`hence + forth`

= 从当前这个点往后  
= **从今以后**

正式程度高于 `from now on`。

## 15. hemisphere

**hemisphere** /ˈhemɪsfɪə(r)/ = 半球

拆分：
`hemi- + sphere`

- `hemi-` = half
- `sphere` = 球

所以：
`hemisphere` = half sphere

常见：
- `Northern Hemisphere`
- `Southern Hemisphere`
- `cerebral hemisphere`

---

## 16. 表示“半”的词缀

### hemi-
= half，严格的一半；希腊来源

- `hemisphere`
- `hemiplegia`

### semi-
= half / partly，半；部分地

- `semicircle`
- `semiconductor`
- `semi-conscious`

### demi-
= half / partly，较少见，法语来源

- `demigod`

### sesqui-
= one and a half，一又二分之一

- `sesquicentennial` = 150 周年

区分：
`hemi-` → 科学、医学、几何中常见  
`semi-` → 最通用  
`demi-` → 固定词、文学历史色彩较多

## 17. gorgeous

**gorgeous** /ˈɡɔːrdʒəs/ = 极漂亮的；华丽的；绚丽的

词源较不规则，不建议硬拆。

## 18. deplore

**deplore** /dɪˈplɔːr/ = 强烈谴责；深感遗憾、悲叹

词源：
`de- + plorare`

`plorare` = cry / lament，哭、哀叹

所以：
`deplore`
→ 强烈哀叹
→ 痛惜
→ 强烈谴责

同族：
- `deplorable` = 可悲的；应受谴责的

核心：
**plor = cry / lament**

## 19. “谴责”词汇组块

不要都压成同一个中文义。

- `criticize` = 普通批评
- `reproach` = 责备，带失望
- `rebuke` = 严厉斥责
- `reprimand` = 正式训斥，上级对下级
- `berate` = 劈头盖脸地训斥
- `castigate` = 猛烈痛斥
- `condemn` = 强烈谴责、道德定罪
- `denounce` = 公开谴责
- `censure` = 正式、官方谴责
- `deplore` = 痛惜 + 谴责

识别轴：
- 公开性 → `denounce`
- 正式性 → `censure / reprimand`
- 道德定罪 → `condemn`
- 痛惜感 → `deplore`
- 当面训斥 → `rebuke / berate`

## 20. hedge

**hedge** /hedʒ/

本义：
= 树篱

引申逻辑：
`篱笆`
→ 保护、隔离
→ 降低风险暴露
→ 金融中的“对冲”

常见：
- `hedge against inflation` = 对冲通胀
- `hedge currency risk` = 对冲汇率风险
- `hedging strategy` = 对冲策略
- `hedge fund` = 对冲基金
- `hedge one's bets` = 两边下注、降低押错风险

语言中还可表示：
“说话留余地、含糊表态”。

核心：
**hedge = 建保护边界 → 降低暴露。**

词源：

语义：
`亲近熟人`

常见：

## 22. amiable

**amiable** /ˈeɪmiəbl/ = 和蔼可亲的；友善的；讨人喜欢的

词源：
`amicus` = friend
← `amare` = love

所以：
`love → friend → friendly`

同族：

区别：

**ami / am = love / friend**

## 27. faint

**faint** /feɪnt/

核心义：
**weak / barely perceptible**

因此有：

1. 虚弱的
   - `feel faint` = 感觉要晕

2. 微弱的
   - `faint light` = 微光
   - `a faint voice` = 微弱的声音

3. 模糊、不明显的
   - `a faint smell` = 淡淡的气味
   - `a faint hope` = 渺茫的希望

4. 动词
   - `faint` = 昏倒

注意三词：
- `faint` = 微弱；昏厥
- `feint` = 佯攻、假动作
- `feign` = 假装

## 今日核心结论

今天最大的收益不是又增加了二十多个孤立单词，而是开始形成几个可以迁移的词根网络：

`claud / clud / clos`
`ple / plete`
`pict`
`sed`
`via`
`vol`
`plor`
`ami`

以后碰到陌生词时，优先判断：

**前缀 + 核心词根 + 后缀 → 原始动作/状态 → 现代语义**

但词源只作为辅助识别工具；像 `gorgeous`、`gown`、`barrel` 这种来源不规则或不确定的词，不应为了“词根化”而强行拆解。
