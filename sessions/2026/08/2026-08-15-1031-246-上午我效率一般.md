# 上午学习总结

## 1. 分部积分：反对幂三指

选 \(u\) 的常见优先顺序：

\[
\boxed{\text{反三角}>\text{对数}>\text{幂}>\text{三角}>\text{指数}}
\]

越靠左通常越优先求导。

例如：

\[
x^k(\ln x)^n
\]

优先考虑：

\[
u=(\ln x)^n
\]

因为：

\[
\boxed{\frac{d}{dx}(\ln x)^n=\frac{n(\ln x)^{n-1}}x}
\]

这样可以让对数幂次下降，形成递推。

---

## 2. 广义积分中值定理

若：

\[
f(x)\text{连续}
\]

\[
g(x)\text{可积且不变号}
\]

则存在：

\[
\xi\in[a,b]
\]

使得：

\[
\boxed{
\int_a^b f(x)g(x)\,dx
=
f(\xi)\int_a^b g(x)\,dx
}
\]

关键：

\[
\boxed{\xi\text{一般不知道具体值，但必须可控}}
\]

不一定非要把 \(\xi\) 消掉，只要能利用：

\[
\xi\in[a,b]
\]

对 \(f(\xi)\) 进行上下界控制即可。

---

## 3. 积分保序性与比较法

若在区间上：

\[
f(x)\le g(x)
\]

则：

\[
\boxed{
\int_a^b f(x)\,dx
\le
\int_a^b g(x)\,dx
}
\]

因此比较法的基本思路是：

\[
\boxed{\text{先比较被积函数，再比较积分}}
\]

例如：

\[
\int_0^1x^nf(x)\,dx
\]

若：

\[
|f(x)|\le M
\]

则：

\[
\left|
\int_0^1x^nf(x)\,dx
\right|
\le
M\int_0^1x^n\,dx
=
\frac{M}{n+1}
\to0
\]

所以：

\[
\boxed{x^n\text{的积分衰减可以控制旁边的有界因子}}
\]

---

## 4. Jordan 不等式

当：

\[
0<x<\frac{\pi}{2}
\]

有：

\[
\boxed{
\frac{2}{\pi}x<\sin x<x
}
\]

等价写法：

\[
\boxed{
\sin x<x<\frac{\pi}{2}\sin x
}
\]

其中：

\[
\sin x<x
\]

是基本不等式；

而：

\[
\frac{2}{\pi}x<\sin x
\]

来自 \(\sin x\) 在 \([0,\pi/2]\) 上的凹性。
