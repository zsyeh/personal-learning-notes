# 二、合同变换的核心定义

若存在可逆矩阵 \(P\)，使

\[
B=P^TAP,
\]

则称 \(A\) 与 \(B\) 合同。

合同关系主要服务于二次型。

若

\[
f(x)=x^TAx,
\]

作可逆变量替换

\[
x=Py,
\]

则

\[
f=x^TAx
=y^TP^TAPy.
\]

因此新二次型的矩阵就是

\[
\boxed{P^TAP}.
\]

所以：

\[
\boxed{\text{变量替换 }x=Py
\iff
A\rightarrow P^TAP}
\]

这是理解所有合同变换的根基。

---

# 三、求 \(C^TAC=B\) 的标准机械方法

若想求可逆矩阵 \(C\)，满足

\[
C^TAC=B,
\]

最稳定的方法是分别把 \(A,B\) 合同化到同一个标准矩阵 \(J\)。

设

\[
C_1^TAC_1=J,
\]

同时

\[
C_2^TBC_2=J.
\]

于是

\[
C_1^TAC_1=C_2^TBC_2.
\]

两边整理：

\[
B=(C_2^{-1})^TC_1^TAC_1C_2^{-1}.
\]

注意

\[
(C_1C_2^{-1})^T
=
(C_2^{-1})^TC_1^T.
\]

因此

\[
B=(C_1C_2^{-1})^T
A
(C_1C_2^{-1}).
\]

所以最终：

\[
\boxed{C=C_1C_2^{-1}}.
\]

这是本次必须形成条件反射的公式。

# 四、为什么不能简单把 \(A,B\) 上下拼起来做

之前考虑过是否可以写成

\[
\begin{pmatrix}
A\\
B
\end{pmatrix}
\]

然后一起进行初等变换。

一般不这样做。

原因是求

\[
C^TAC=B
\]

时，实际上需要分别得到两个变换矩阵：

\[
A\xrightarrow{C_1}J,
\qquad
B\xrightarrow{C_2}J.
\]

然后再拼：

\[
C=C_1C_2^{-1}.
\]

增广单位阵 \(E\) 的意义是“记录累计做过的变量变换”。

所以机械方法的思想是：

\[
(A,E)\rightarrow(J,C_1),
\]

以及

\[
(B,E)\rightarrow(J,C_2).
\]

关键不是把 \(A,B\) 绑在一起，而是分别记录各自的变换。

# 五、本次矩阵求逆的结论

一开始复习了各种求逆快捷方式，但最终决定：

## 1. 二阶矩阵

对于

\[
A=
\begin{pmatrix}
a&b\\
c&d
\end{pmatrix},
\]

直接：

\[
A^{-1}
=
\frac1{ad-bc}
\begin{pmatrix}
d&-b\\
-c&a
\end{pmatrix}.
\]

口诀：

- 主对角交换
- 副对角变号
- 除以行列式

---

## 2. 三阶矩阵

没必要额外背很多三角矩阵求逆公式。

保留两套通用工具即可。

### 方法一：伴随矩阵

\[
\boxed{
A^{-1}=\frac1{|A|}A^*
}
\]

适合：

- 二阶矩阵
- 三阶矩阵中大量元素为 0
- 已知 \(A^*\)
- 已知 \(|A|\)
- 余子式特别容易算

### 方法二：增广矩阵

\[
\boxed{
(A\mid E)
\rightarrow
(E\mid A^{-1})
}
\]

适合：

- 普通三阶矩阵
- 伴随矩阵需要计算很多余子式
- 数字结构一般

本次结论：

\[
\boxed{\text{不需要为了偶尔出现的特殊矩阵额外背很多求逆公式}}
\]

判断哪个计算量小，就用哪个。

# 六、合同关系保持哪些性质

若

\[
B=P^TAP,
\qquad P\text{ 可逆},
\]

则有很多非常重要的性质。

## 1. 秩保持

因为左右乘可逆矩阵不改变秩：

\[
\boxed{r(A)=r(B)}.
\]

这是本次非常重要的遗漏点。

以后看到合同关系，应该第一时间检查：

\[
\boxed{\text{两边有没有明显秩亏？}}
\]

---

## 2. 行列式符号保持

因为

\[
|B|
=
|P^T||A||P|
=
|P|^2|A|.
\]

由于 \(P\) 可逆，

\[
|P|^2>0.
\]

因此：

\[
\boxed{
\operatorname{sgn}|A|
=
\operatorname{sgn}|B|
}
\]

注意：

一般不是

\[
|A|=|B|,
\]

而只是符号相同。

---

## 3. 正负惯性指数保持

这是 Sylvester 惯性定律：

合同矩阵具有相同的：

- 正惯性指数
- 负惯性指数
- 零惯性指数

因此规范形相同。

若一个矩阵合同化为

\[
\operatorname{diag}(1,1,-1,0),
\]

另一个也必须有：

- 2 个正平方项
- 1 个负平方项
- 1 个零项

---

## 4. 对称性

如果

\[
A^T=A,
\]

那么

\[
B=P^TAP
\]

一定也满足

\[
B^T=B.
\]

证明：

\[
B^T
=
(P^TAP)^T
=
P^TA^TP
=
P^TAP
=
B.
\]

因此：

\[
\boxed{
A\text{ 对称}
\Rightarrow
B\text{ 对称}
}
\]

---

\begin{pmatrix}

\end{pmatrix},
\qquad

\begin{pmatrix}

\end{pmatrix},

\boxed{

\text{矩阵结构}

+
\text{关系类型}

- \(A\) 是否对称？

A=

其中

J=

因为

\begin{pmatrix}

再补

\[
(1-a)I
\]

# 九、为什么 \(J\) 是秩 1 矩阵

可以写成

\[
J=
\begin{pmatrix}
1\\1\\1
\end{pmatrix}
\begin{pmatrix}
1&1&1
\end{pmatrix}.
\]

所以

\[
r(J)=1.
\]

其特征值为：

\[
3,0,0.
\]

其中

\[
\begin{pmatrix}
1\\1\\1
\end{pmatrix}

对应特征值 3。

而满足

\[
x_1+x_2+x_3=0
\]

# 十、\(A=(1-a)I+aJ\) 的特征值

因为

\[
A=(1-a)I+aJ,
\]

所以在方向

\[
(1,1,1)^T
\]

上：

\[
\lambda_1
=
(1-a)+3a
=
1+2a.
\]

而在平面

\[
x_1+x_2+x_3=0
\]

上，

\[
Jx=0,
\]

所以：

\[
\lambda_2=\lambda_3=1-a.
\]

因此：

\[
\boxed{
\lambda_1=1+2a,
\qquad
\lambda_2=\lambda_3=1-a
}
\]

于是：

\[
\boxed{
|A|=(1+2a)(1-a)^2
}
\]

这是非常高效的结构识别结果。

# 十一、2020 数二题：为什么 \(a=-\frac12\)

题目中：

\[
A=
\begin{pmatrix}
1&a&a\\
a&1&a\\
a&a&1
\end{pmatrix}
\]

经过可逆线性变换得到：

\[
B=
\begin{pmatrix}
1&1&0\\
1&1&0\\
0&0&4
\end{pmatrix}.
\]

因为是合同关系：

\[
B=P^TAP.
\]

观察 \(B\)：

前两行相同，第三行独立。

因此：

\[
\boxed{r(B)=2}.
\]

所以：

\[
\boxed{r(A)=2}.
\]

而 \(A\) 的特征值为：

\[
1+2a,\quad 1-a,\quad 1-a.
\]

若

\[
a=1,
\]

则：

\[
\lambda=(3,0,0),
\]

所以：

\[
r(A)=1.
\]

不符合。

若

\[
a=-\frac12,
\]

则：

\[
\lambda=
\left(
0,\frac32,\frac32
\right),
\]

所以：

\[
r(A)=2.
\]

符合。

因此：

\[
\boxed{
a=-\frac12
}
\]

# 十二、行和为 0 是一个非常强的信号

当

\[
a=-\frac12
\]

时：

\[
A=
\begin{pmatrix}
1&-\frac12&-\frac12\\
-\frac12&1&-\frac12\\
-\frac12&-\frac12&1
\end{pmatrix}.
\]

每行元素之和都是 0。

于是：

\[
A
\begin{pmatrix}
1\\1\\1
\end{pmatrix}
=
0.
\]

所以：

\[
\boxed{
(1,1,1)^T
\text{ 是 }\lambda=0\text{ 的特征向量}
}
\]

立刻得到：

\[
|A|=0,
\]

且矩阵秩下降。

这说明：

\[
\boxed{
\text{行和为常数 }s
\Rightarrow
(1,1,\dots,1)^T
\text{ 是特征向量，特征值为 }s
}
\]

特别地：

\[
\boxed{
\text{行和为0}
\Rightarrow
0\text{ 是特征值}
}
\]

# 十三、行和为 0 还可以直接指导合同变换

对于：

\[
A=
\begin{pmatrix}
1&-\frac12&-\frac12\\
-\frac12&1&-\frac12\\
-\frac12&-\frac12&1
\end{pmatrix},
\]

由于

\[
C_1+C_2+C_3=0,
\]

可以直接做：

\[
C_3\leftarrow C_1+C_2+C_3.
\]

合同变换要求同步：

\[
R_3\leftarrow R_1+R_2+R_3.
\]

于是直接得到：

\[
A\sim
\begin{pmatrix}
1&-\frac12&0\\
-\frac12&1&0\\
0&0&0
\end{pmatrix}.
\]

三阶问题立刻降成二阶。

然后：

\[
C_2\leftarrow C_2+\frac12C_1,
\]

同步：

\[
R_2\leftarrow R_2+\frac12R_1.
\]

得到：

\[
\operatorname{diag}
\left(
1,\frac34,0
\right).
\]

最后缩放即可得到规范形：

\[
\boxed{
\operatorname{diag}(1,1,0)
}
\]

这一过程非常重要：

\[
\boxed{
\text{发现列之间线性关系}
\Rightarrow
\text{优先直接把某一列消成0}
}
\]

# 十四、这道题其实正交对角化更简单

同一个矩阵：

\[
A=
\begin{pmatrix}
1&-\frac12&-\frac12\\
-\frac12&1&-\frac12\\
-\frac12&-\frac12&1
\end{pmatrix}
\]

特征值已经知道：

\[
\frac32,\frac32,0.
\]

零特征值对应：

\[
\alpha_3=(1,1,1)^T.
\]

对于特征值

\[
\frac32,
\]

特征空间为：

\[
x_1+x_2+x_3=0.
\]

可以直接取两个彼此正交的简单向量：

\[
\alpha_1=(1,-1,0)^T,
\]

\[
\alpha_2=(1,1,-2)^T.
\]

它们满足：

\[
\alpha_1^T\alpha_2=0.
\]

单位化：

\[
q_1=
\frac1{\sqrt2}(1,-1,0)^T,
\]

\[
q_2=
\frac1{\sqrt6}(1,1,-2)^T,
\]

\[
q_3=
\frac1{\sqrt3}(1,1,1)^T.
\]

令：

\[
Q=(q_1,q_2,q_3),
\]

则：

\[
\boxed{
Q^TAQ
=
\operatorname{diag}
\left(
\frac32,\frac32,0
\right)
}
\]

因此这题的策略结论是：

\[
\boxed{
\text{结构明显时，不应该执着于机械初等合同变换}
}
\]

如果特征值和特征向量非常容易得到，正交对角化可能更快。

# 十五、正交对角化本身也是合同变换

正交矩阵满足：

\[
Q^TQ=I.
\]

所以：

\[
Q^{-1}=Q^T.
\]

因此：

\[
Q^TAQ
=
Q^{-1}AQ.
\]

这同时符合：

### 相似变换

\[
P^{-1}AP
\]

的形式；

也符合：

### 合同变换

\[
P^TAP
\]

的形式。

因此：

\[
\boxed{
Q^TAQ
\text{ 同时是相似变换和合同变换}
}
\]

可以压缩记成：

\[
\boxed{
\text{正交变换 = 既相似，又合同}
}
\]

这里指的是矩阵变换

\[
Q^TAQ.
\]

# 十六、相似变换、合同变换、正交变换的区别

## 1. 相似变换

形式：

\[
\boxed{
B=P^{-1}AP
}
\]

保持：

- 特征值
- 特征多项式
- 迹
- 行列式
- 秩
- Jordan 结构

本质：

同一个线性变换在不同基下的矩阵表示。

---

## 2. 合同变换

形式：

\[
\boxed{
B=P^TAP
}
\]

保持：

- 秩
- 正惯性指数
- 负惯性指数
- 零惯性指数
- 行列式符号
- 对称性

一般不保持：

- 特征值
- 迹
- 行列式具体数值

本质：

二次型变量替换。

---

## 3. 正交变换

若：

\[
Q^TQ=I,
\]

则：

\[
Q^{-1}=Q^T.
\]

于是：

\[
Q^TAQ
=
Q^{-1}AQ.
\]

所以它同时享有：

- 相似变换性质
- 合同变换性质

特别重要：

\[
\boxed{
\text{正交变换保持具体特征值}
}
\]

普通合同只能保持正负惯性。

---

# 十七、“尺度”直觉对应的严格数学语言

本次第二问中曾产生直觉：

> 正交变换是不是要求前后尺度一样？

这个直觉实际上是对的。

普通合同允许缩放：

例如：

\[
\operatorname{diag}(3,2,0)
\]

可以合同化为：

\[
\operatorname{diag}(1,1,0).
\]

因为可以对变量进行缩放。

但正交变换只能进行：

- 旋转
- 反射

不能伸缩。

因此正交变换不能把：

\[
3
\]

变成：

\[
1.
\]

严格来说：

\[
Q^TAQ
=
Q^{-1}AQ
\]

属于相似变换，所以必须保持特征值。

因此：

\[
\boxed{
\text{普通合同看惯性}
}
\]

而：

\[
\boxed{
\text{正交合同看完整特征值}
}
\]

---

# 十八、判断是否存在正交变换的最快方法

如果题目问：

是否存在正交矩阵 \(Q\)，使：

\[
Q^TAQ=B?
\]

因为：

\[
Q^T=Q^{-1},
\]

所以：

\[
B=Q^{-1}AQ.
\]

因此：

\[
A,B
\]

必须相似。

最快可以先检查相似不变量。

例如：

### 第一优先级：迹

\[
\operatorname{tr}A
\stackrel{?}{=}
\operatorname{tr}B.
\]

若不同：

\[
\boxed{\text{直接不存在}}
\]

### 第二优先级：行列式

\[
|A|
\stackrel{?}{=}
|B|.
\]

### 第三优先级：特征值

若仍无法判断，再比较完整特征值。

对于实对称矩阵：

若两者特征值完全相同（含重数），则可以通过正交对角化说明存在正交变换。

# 十九、普通合同与正交合同的判断层级

以后看到：

\[
P^TAP=B
\]

先问：

\[
P\text{ 只是可逆，还是正交？}
\]

若只是可逆：

重点检查：

\[
\boxed{
r,\quad
p,q,\quad
\operatorname{sgn}|A|
}
\]

若 \(P=Q\) 正交：

还可以检查：

\[
\boxed{
\operatorname{tr},
\quad
|A|,
\quad
\lambda_i
}
\]

因为此时也是相似变换。

# 二十、分数不是复杂度指标

本次非常明显的一个做题障碍：

看到：

\[
\frac12,\frac34,\frac14
\]

容易产生：

> 后面是不是会越来越麻烦？

然后提前停止。

实际上：

\[
\operatorname{diag}
\left(
1,\frac34,0
\right)
\]

虽然出现了分母 4，但已经几乎完全做完。

真正的复杂度应该看：

1. 非零非对角元素还剩多少
2. 表达式项数是否变多
3. 参数是否越来越耦合
4. 矩阵是否越来越接近对角形式

因此：

\[
\boxed{
\text{分数多}
\not\Rightarrow
\text{复杂}
}
\]

反而：

\[
\boxed{
\text{非对角元减少}
\Rightarrow
\text{通常是在变简单}
}
\]

# 二十一、出现分数后的新规则

以后如果第一次出现：

\[
\frac12,\frac14,\frac34,\frac13,\frac23,
\]

不要因为分数直接换路线。

规定：

\[
\boxed{
\text{第一次出现分数后，至少继续两步，再评价路线}
}
\]

即：

以前：

\[
\text{出现分数}
\rightarrow
\text{担心算错}
\rightarrow
\text{停止}.
\]

现在改成：

\[
\boxed{
\text{出现分数}
\rightarrow
\text{看结构有没有变简单}
\rightarrow
\text{继续2步}
\rightarrow
\text{再判断}
}
\]

---

# 二十二、本次做题中暴露出的核心认知问题

这次最明显的问题不是知识不会。

而是多次出现：

\[
\text{发现正确结构}
\rightarrow
\text{产生正确猜想}
\rightarrow
\text{觉得依据还不够}
\rightarrow
\text{不敢继续}
\]

典型例子：

## 例 1

看到：

\[
a=-\frac12
\]

时行和为 0。

其实已经接近：

\[
A(1,1,1)^T=0.
\]

只差把直觉转成数学语言。

---

## 例 2

想到：

> 正交变换是不是前后“尺度”必须一样？

其实只差：

\[
Q^T=Q^{-1}
\]

于是：

\[
Q^TAQ=Q^{-1}AQ.
\]

立刻得到相似关系。

---

## 例 3

发现合同后的矩阵秩不满。

一开始觉得：

> 为什么会出现 0？

其实这个 0 本身就是出题点：

\[
r(A)=r(B).
\]

---

# 二十三、以后遇到“我感觉是不是……”时的处理规则

不要立刻抛弃直觉。

规定：

\[
\boxed{
\text{出现一个结构猜想}
\Rightarrow
\text{必须把它写成一个公式}
}
\]

例如：

### “行和是不是 0？”

立刻写：

\[
A\mathbf1=0.
\]

---

### “是不是秩不满？”

立刻写：

\[
r(A)=?
\]

---

### “是不是正交变换不能缩放？”

立刻写：

\[
Q^T=Q^{-1}.
\]

---

### “是不是相似？”

立刻检查：

\[
\operatorname{tr},\quad |A|,\quad \lambda.
\]

目标：

\[
\boxed{
\text{把模糊直觉翻译成数学命题}
}
\]

而不是要求直觉一开始就必须完整严谨。

---

# 二十四、做合同题时的推荐 SOP

以后看到：

\[
C^TAC=B
\]

先不要立刻消元。

## Step 1：检查题干

看：

- \(A,B\) 是否对称
- 参数是否整数
- \(C\) 是否可逆
- 是否要求 \(C\) 正交
- 是否有特殊数值范围

---

## Step 2：检查不变量

优先检查：

\[
r(A),r(B)
\]

\[
\operatorname{sgn}|A|,
\operatorname{sgn}|B|
\]

\[
p(A),q(A)
\]

如果要求正交，再检查：

\[
\operatorname{tr},
\quad
|A|,
\quad
\lambda.
\]

---

## Step 3：观察结构

检查：

- 行和
- 列和
- 重复行
- 重复列
- 对角元素是否相同
- 非对角元素是否相同
- 是否可写成
  \[
  \alpha I+\beta J
  \]
- 是否存在明显秩 1 部分
- 是否有简单特征向量

---

## Step 4：选路线

### 结构简单、特征值明显：

优先正交对角化。

### 有明显行列关系：

优先初等合同直接消一行一列。

### 普通矩阵：

使用机械合同变换。

---

## Step 5：分别化到同一个 \(J\)

\[
C_1^TAC_1=J
\]

\[
C_2^TBC_2=J.
\]

---

## Step 6：拼变换矩阵

\[
\boxed{
C=C_1C_2^{-1}
}
\]

---

## Step 7：最终验证

不要只和答案逐元素比较。

直接检查：

\[
\boxed{
C^TAC=B
}
\]

如果成立且：

\[
|C|\neq0,
\]

就是正确答案。

合同变换矩阵通常不唯一。

---

# 二十五、关于“答案符号和参考答案反了”

本次有一道题最终得到的矩阵与视频答案形式不同，因此怀疑符号错误。

但直接验证：

\[
P^TAP=B
\]

成立。

说明：

\[
\boxed{
P\text{ 是正确答案}
}
\]

重要结论：

\[
\boxed{
\text{合同变换矩阵通常不唯一}
}
\]

所以不能要求自己的 \(P\) 与参考答案逐项相同。

真正的判据只有：

\[
P^TAP=B.
\]

这比“和答案长得一样”可靠得多。

# 二十七、本次学习状态评价

本次学习并不是“知识点完全陌生”。

实际上多数关键方向已经能够自己发现：

- 发现 \(a=-1/2\) 时行和为 0
- 发现秩亏可能是题目核心
- 发现正交变换不能随意改变“尺度”
- 发现某些矩阵正交对角化比机械合同更简单
- 能够独立推导
  \[
  C=C_1C_2^{-1}
  \]
- 简单合同题速度已经可以做到约 3 分钟

当前主要瓶颈是：

\[
\boxed{
\text{正确结构已经出现，但没有继续追到严格结论}
}
\]

以及：

\[
\boxed{
\text{对分数、非标准答案形式、陌生中间结果过度警觉}
}
\]

因此下一阶段不需要大量增加新公式。

更应该训练：

1. 题干条件扫描
2. 不变量扫描
3. 结构观察
4. 将直觉写成公式
5. 出现分数后继续推进
6. 最后用定义验证，而不是和答案外形比较

# 二十八、下一阶段训练重点

## A 类：合同不变量参数题

并快速选择：

作为最低成本判据。
