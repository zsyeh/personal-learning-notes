# platu

本次词源总结

1. 拉丁 / 希腊词根类

adversity

* ad- = toward
* vers / vert = turn
* -ity = 状态
* adversity = 局势“转向不利” → 逆境

同源：adverse, reverse, convert, invert, versatile, controversy

pneumonia

* pneum / pneumon = lung / breath
* -ia = 疾病、状态
* pneumonia = 肺部疾病 → 肺炎

同源：pneumatic, pneumothorax
另一“肺”词根：pulmon- → pulmonary

denounce

* de- = 强化/离开
* nounce / nunc = speak, announce
* denounce = 公开说反对的话 → 谴责

同源：announce, pronounce, renounce, enunciate

dispute

* dis- = apart
* put(e) = think / reckon
* dispute = 想法分开 → 争论、质疑

同源：compute, repute, reputation, impute

proposal

* pro- = forward
* pos / pon = put, place
* proposal = 放到前面 → 提议

同源：propose, compose, impose, expose, dispose

pro-

核心不是很多完全独立的意思，而是：
pro = forward（向前）

引申：

* 向前 → progress
* 推向前 → promote
* 放到前面 → propose
* 公开向前说 → proclaim / profess
* 站在某一方前面 → pro- = 支持

plagiarism

来自拉丁语 plagiarius = kidnapper

* 原义：绑架者
* 后来：“绑架别人的文字/思想”
* → 剽窃、抄袭

派生：plagiarize, plagiarist

naval

* nav- = ship
* naval = 船/海军的 → 海军的

同源：navy, navigate, navigation

vicinity

* vicin- = neighboring, near
* vicinity = 邻近区域 → 附近

eligible

* e-/ex- = out
* leg / lig = choose
* -ible = 可被……
* eligible = 可以被选出来 → 有资格的

同源：elect, election, select, collect

empirical

来自希腊语，核心：

* peira = trial, experience
* empirical = 通过经验和试验得到的 → 经验性的、实证的

相关：experience, experiment

emigrate

* e-/ex- = out
* migr- = move
* emigrate = move out → 迁出、移居国外

对比：

* emigrate from
* immigrate to

textile

* tex / text = weave
* textile = 编织物 → 纺织品

同源：

* text = 词句“编织”成文章
* texture = 编织形成的质地
* context = 内容织在一起 → 上下文

eloquent

* e-/ex- = out
* loqu / locut = speak
* eloquent = 把话有力地说出来 → 雄辩的、有感染力的

同源：eloquence, loquacious, colloquial, soliloquy

delegate

* legare = send / appoint
* delegate = 派某人代表自己 → 代表；委派

同源：delegation, legate, relegate

refuge

* re- = back / away
* fug / fugit = flee
* refuge = 逃离危险后躲进去 → 避难所、庇护

同源：

* refugee = 难民
* fugitive = 逃亡者
* centrifuge = “逃离中心” → 离心机

allegiance

来源于中古法语、封建制度中的 liege

* liege = 你负有忠诚义务的领主
* allegiance = 对领主的效忠关系
* → 忠诚、效忠

注意：

* alliance = 联盟
* allegiance = 忠诚

⸻

2. 日耳曼 / 英语本土词：不适合硬拆词根

slum

核心：贫穷破败的城区

* slum = 贫民窟
* slumlord = 贫民窟房东
* slum it = 暂时将就住在较差环境

不要和 slump = 暴跌、低迷 混。

queer

早期核心：斜的、偏离正常方向
→ strange
→ 奇怪的
→ 后来发展出现代 queer 社会文化义

shaft

核心：long straight object

* arrow shaft = 箭杆
* drive shaft = 传动轴
* mine shaft = 井筒
* get shafted = 被坑

thorn

核心：sharp point

* thorn = 刺、荆棘
* a thorn in one’s side = 肉中刺

古英语字母 Þ/þ 也叫 thorn。

sheer

主要义：

1. pure / complete → 纯粹的、十足的
    * sheer luck
2. vertical → 陡峭的
    * sheer cliff
3. transparent → 薄而透明的
    * sheer curtain

注意：

* sheer = 纯粹的
* shear = 剪切

quiver

两个不同来源的词：

1. quiver = 微微颤抖
2. quiver = 箭袋

chill

核心：cold
→ 寒冷
→ 冷却
→ 情绪“降温”
→ chill out = 放松、冷静

chorus

来自希腊语 khoros = group singing / dancing
→ 合唱
→ 合唱队
→ 歌曲副歌

相关：choir

grief

深层核心与 grav = heavy 有关：

* heavy → 心理沉重
* → grief = 悲痛

同源：

* grave = 严重的
* gravity = 重力
* aggravate = 加重
* grieve = 悲伤
* grievous = 严重的

territory

* terr- = earth / land
* territory = 一块受控制的土地 → 领土、地域

同源：

* terrain
* terrestrial
* subterranean
* Mediterranean

chunk

核心：thick solid piece
→ 一大块
→ 一大部分
→ 一块数据/内容

派生：chunky, chunking

aisle

来自“wing / building side”
→ 建筑侧翼
→ 侧廊
→ 过道

发音：/aɪl/

区分：

* aisle = 过道
* isle = 小岛
* I’ll = I will

feeble

来自拉丁语表示“哭泣、可怜”的词
→ 可悲
→ 弱小
→ 虚弱的、无力的

flare

核心动态图像：
suddenly spread outward / become brighter

→ 火焰腾起
→ solar flare
→ flare up = 突然爆发/恶化
→ 衣物向外展开
→ signal flare = 信号弹

embark

* em-/en- = into
* barque / bark = ship
* embark = 进入船中 → 上船
* 后来 → 开始、着手
* embark on a project
* embark on a journey

反义：disembark = 下船/下飞机

grind

核心：反复摩擦，把东西磨掉

→ 研磨
→ grind coffee
→ grind one’s teeth
→ 长期消耗
→ the daily grind = 日复一日辛苦工作
→ grind hard = 苦干

shampoo

来自印地语/乌尔都语，原义：
按摩、揉捏、按压

→ 按摩头皮
→ 洗头时揉搓
→ 洗头
→ 洗发水

massage

核心：touch / press / knead
→ 揉捏、按摩

抽象义：

* massage the data = 人为调整、润色数据
