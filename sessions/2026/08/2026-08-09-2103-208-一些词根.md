# 一些词根

本次对话核心是在建立一套“不要死背现代英语词形，而是追到拉丁/日耳曼原词和异形词干”的词源记忆方法。

核心方法

1. 英语词根不是固定字符串，经常来自拉丁动词不同词干：
    * mittere → mit / miss
    * sequi → sequ / secut
    * facere → fac / fic / fact / fect
    * capere → cap / cip / cept / ceive
2. 很多词经过拉丁语变位 + 法语中转 + 音变后，现代词形和原词已经差很多。
3. 最有效的记法是：
    原始物理动作 → 抽象语义 → 现代词义
    而不是硬拆几个字母。

本次词汇网络

* reap：古英语“收割” → 收获；和 ripe 有历史联系。
* rape：拉丁 rapere = seize/snatch → 强夺 → 强奸。和 reap 不同源。
* harsh：古日耳曼/北欧语系，核心感觉是 rough/coarse → 粗糙、刺耳、严厉、恶劣。
* redundant：
    unda = wave → redundare = overflow → 多出来 → 多余的、冗余的
    * undulate 波动
    * inundate 淹没
    * abundant 丰富
* unda 才是真正的拉丁词“波浪”，und-只是英语词根分析时截出的形式。
    * 法语 onde = wave
    * 德语普通“波浪”主要是 Welle

高价值拉丁母词

* capere = take → ceive / cept
* facere = make/do → fic / fact / fect
* jacere = throw → ject
* cedere = go/yield → cede / ceed / cess
* ferre = carry → fer / lat
* mittere = send → mit / miss
* plicare = fold → plic / ply
* salire = jump → sal / sil / sult
* tendere = stretch → tend / tent / tens
* trahere = drag → tract
* venire = come → ven / vent
* sequi = follow → sequ / secut

本次具体词

texture

* texere = weave
* 编织 → 编织结构 → 纹理、质地
* 同族：text, textile, context
* 核心：text 和 textile 本质上都是“编织”。

omit

* omittere ← mittere = send / let go
* 放掉、搁置 → 省略
* omit → omission
* 同族：
    permit → permission
    submit → submission
    transmit → transmission
    emit → emission

defer

* “推迟”这一义与 ferre = carry 有关
* 把事情从现在“搬走” → 延期
* differ 与它有历史词源联系。
* 另一个 defer to sb = 听从某人 要单独理解。

delay

* 经法语进入英语，核心是 leave / leave something sitting
* 把事情放着不推进 → 延迟
* 与 lax = loose 有更深的历史联系。

refrain

* 动词“克制” ← 拉丁 frenum = bridle（马嚼子/缰具）
* 核心：
    给自己的冲动套缰绳 → hold back → 克制
* 常见：refrain from doing

persecute

* per- + sequi = follow all the way
* 一路追着不放 → 迫害
* sequi → sequ / secut
* 同族：
    * sequence：一个跟一个
    * subsequent：随后
    * consecutive：连续
    * prosecute：法律上追究 → 起诉
    * persecute：追逼 → 迫害
* -cute 不是后缀，真正需要识别的是 secut-。

smuggle

* 日耳曼/荷兰-低地德语来源
* 核心：sneak / creep / secretly move
* 偷偷弄过去 → 走私
* 与 smoke 不同源。

slump

* 日耳曼/北欧语系，带明显动作感
* 突然塌下去、陷下去
* → 人瘫下去
* → 销量/经济/状态暴跌、低迷
* 核心：suddenly sink/fall down

smash

* 日耳曼/拟声型词
* 猛烈撞击 → 砸碎
* → smash a record 大幅打破纪录
* 适合靠“声音 + 动作”记，不适合拉丁词根拆解。

defect

* deficere ← facere = do/make
* 做不到 / 缺下来 → 缺陷
* facere → fic / fect
* 同族：
    * deficient：不足的
    * deficiency：不足
    * effect：做出来的结果
    * perfect：彻底做完 → 完美
* 一句话记：
    defect = 没做到位的地方。

本次最重要的认知

不要问“这几个字母是什么意思”，而要问“这个现代词来自哪个古代原词，那个原词最初表示什么动作”。

这样才能真正解释：
texture ← weave、redundant ← wave/overflow、persecute ← follow、defect ← do/make、omit ← send/let go 这些表面上完全看不出来的关系。
